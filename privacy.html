OPTIMUS 개인정보처리방침

OPTIMUS는 개발자 본인 한 사람만 사용하는 개인용 프로그램입니다.

수집하는 정보

사용자 본인이 연결한 Google 계정의 메일·일정 정보와 Google Assistant 응답을, 사용자가 요청한 순간에만 Google API로 조회합니다.

저장과 보관

인증 토큰은 사용자의 노트북에 Windows 데이터 보호(DPAPI)로 암호화해 저장합니다. 조회한 메일 본문은 요청을 처리한 뒤 저장하지 않으며, 요약과 기록은 사용자의 노트북에만 남습니다. 외부 서버에 사용자 데이터를 보관하지 않습니다.

제3자 제공

판매하거나 광고에 쓰지 않습니다. 사용자가 분석을 맡긴 경우에 한해 요청 내용 일부가 사용자가 구독한 AI 서비스(Anthropic Claude, OpenAI Codex)로 전달될 수 있습니다.

삭제

OPTIMUS 설정에서 Google 계정 연결을 해제하면 저장된 토큰이 삭제됩니다. Google 계정 권한 페이지에서도 언제든 접근 권한을 철회할 수 있습니다.

Google API 사용

OPTIMUS의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

문의

이 프로그램의 사용자이자 개발자 본인에게 문의합니다.
